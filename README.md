# COMMERCE-T3 — Regarde comment ça marche

**Étape actuelle : [choisir les transitions du premier lot de quatre vidéos](research/lot-01.md).**

- [Six questions](form/questions.json), séparées de la capture. Seul le prix est facultatif. La quatrième réponse précise ce que le commerçant veut démontrer, pas une accroche commerciale.
- [Douze écrans proposés](capture-guide/ecrans.json) : pour chaque scène, guide A, enregistrement B et vérification C. Le même produit prêt (6 s), la partie à utiliser (8 s), un seul geste (7 s), le résultat réel (9 s). Parole libre ou silence.

Ce dépôt initialise le brief. Aucune transition, musique ou voix retenue, aucun moteur ni déploiement activé. Après le choix, analyser uniquement les raccords retenus et proposer leur adaptation aux quatre prises.
